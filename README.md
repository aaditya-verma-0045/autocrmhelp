# AUTO CRM HELP

This repository stores the website content, landing pages, campaigns, case studies, assets, and automation planning for AUTO CRM HELP.

AUTO CRM HELP helps businesses automate CRM workflows, lead management, reporting, operations, and AI-powered business processes.

## Repository Structure

- `/pages` - Website and landing page copy
- `/case-studies` - Client case studies and portfolio examples
- `/campaigns` - Email, Facebook, LinkedIn, and outreach campaigns
- `/wordpress` - WordPress notes, Elementor instructions, custom CSS and JS
- `/assets` - Image, icon, and visual asset notes
- `/docs` - Internal strategy, SOPs, and planning documents
